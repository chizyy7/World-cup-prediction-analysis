# World Cup AI Predictor (1998–2022)

Production-style full-stack FIFA World Cup prediction project with:

- **Frontend**: Next.js 15 (App Router) + TypeScript + Tailwind + shadcn-style UI components + Framer Motion + Recharts
- **Backend**: FastAPI + Python ML inference API
- **ML Pipeline**: Feature preparation, model training, persisted artifacts, and explainable prediction responses

## Features

- Dashboard champion probability ranking + charts
- Searchable country profile pages with trend charts
- Historical World Cup tournament summary
- Team comparison radar chart
- Match outcome prediction with confidence split
- Knockout simulation with winner distribution
- AI-style explanation text for every prediction endpoint
- Dark/light theme toggle
- Loading/fallback states and API-fallback fixtures

## Repository Layout

- `/frontend` – Next.js 15 web app (all required routes)
- `/backend` – FastAPI app, model/data pipeline, tests, artifacts

## Backend: Data + ML Design

Training period: **1998–2022**. The pipeline includes these model features:

- `fifa_rank`
- `elo_rating`
- `recent_form`
- `goals_scored`
- `goals_conceded`
- `possession`
- `xg`
- `squad_market_value`
- `average_age`
- `manager_experience`
- `wc_pedigree`

If external/source-complete fields are unavailable, the pipeline still runs using deterministic fallback generation (`backend/scripts/prepare_features.py`) so training/inference remains reproducible.

## Backend API Endpoints

- `GET /health`
- `GET /teams`
- `GET /teams/{team}`
- `GET /history/world-cups`
- `POST /predict/champion`
- `POST /predict/match`
- `POST /predict/knockout`

Each prediction response includes concise explanation text.

## Quickstart

### 1) Backend

```bash
cd backend
python -m pip install -r requirements.txt
python scripts/prepare_features.py
python scripts/train_model.py
uvicorn app.main:app --reload --port 8000
```

Standalone historical prediction PNG (no app required):

```bash
cd backend
python scripts/world_cup_prediction_png.py
```

This saves a chart at `backend/app/artifacts/world_cup_prediction_2022.png`.

### 2) Frontend

```bash
cd frontend
npm install
npm run dev
```

Set API base URL if needed:

```bash
# frontend/.env.local
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
```

Open `http://localhost:3000`.

## Training + Evaluation

Artifacts are persisted under `backend/app/artifacts/`:

- `champion_model.joblib`
- `evaluation.json`

Current baseline metrics are generated by `python scripts/train_model.py`.
